POST
/api/v1/products/parts
Create a new part


Creates a standalone part that can later be linked to one or more products.

Image upload (optional, multipart/form-data)
Same convention as POST /products:

Field	Type	Description
name, partCategory, ...	string	All JSON fields as form-data fields
specifications	JSON string	[{"name":"Material","value":"Glass"}]
images[]	file	jpeg/png/webp, max 10MB each, max 10 files
imageAlt_0	string	Alt text for file at index 0
imagePrimary_0	"true"	Mark file at index 0 as primary
imageSortOrder_0	number	Sort position for file at index 0
Images upload synchronously before the 201 response.

Rate limit: 30 part creates / hour per staff member.
